# WOTS
Running Xbox Series X|S games natively on PC: our working builds of XCL (GPL-2.0) and Leonida, the native PC recompilation of the Xbox version of GTA VI (GPL-3.0). No game files here: use your own legally owned copy.
Get the code: `git clone -b xcl https://github.com/hidrogenone/wots xcl` · `git clone -b leonida-boot https://github.com/hidrogenone/wots leonida` (newest boot work; `leonida` = merged PRs only). Build steps are in each branch's README.
